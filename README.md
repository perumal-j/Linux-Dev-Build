# Linux-Dev-Build

Linux-Dev-Build is an Ansible project customizes your VM for Development activities. It can mainly be used in Ubuntu OS(Parrot too). 

## Prerequisite:
Firstly, Run `ansible_installation.sh` to install ansible & other components for hassle free ubuntu building.
